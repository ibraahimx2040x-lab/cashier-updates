# رفيق · Rafiq

موقع دردشة مع شخصيات خيالية (مو تطبيق) — تكتشف شخصيات، تسولف معها، وتصنع شخصيتك الخاصة.

A website for chatting with fictional AI characters: discover, chat, and create your own.

## الميزات
- **اكتشف**: شخصية مميزة يوميًا، تصنيفات (أصدقاء، مغامرة، أنمي، خيال، غموض، خيال علمي، رعب، تعلّم، حكايات)، وبحث.
- **المحادثة**: ردود تظهر حرفًا بحرف، الحركات بين نجمتين `*تبتسم*` تظهر مائلة، زر «رد ثاني»، نسخ، إيقاف، محادثة جديدة، حذف.
- **ارسم المشهد 🎨**: تحت كل رسالة فيها حركة بين نجمتين، يرسم الذكاء الاصطناعي المشهد بأسلوب أنمي وبنفس شكل الشخصية (`supabase/functions/character-scene`، نموذج `gemini-3.1-flash-image`). الرسمة تنحفظ مع الرسالة، وتقدر تكبّرها أو تحمّلها أو ترسمها من جديد.
- **اصنع شخصيتك**: الاسم، الصورة (شكل أنمي تصممه: الشعر والعيون والبشرة واللبس والإكسسوار، أو إيموجي، أو صورة ترفعها)، الوصف، الشخصية، المشهد، أول رسالة، التصنيف.
- **المحادثات**: قائمة بآخر المحادثات.
- **حسابي**: اسمك في القصص، العربية/English، داكن/فاتح.
- يشتغل على الجوال والكمبيوتر، يمين لليسار ويسار لليمين.

الشخصيات والمحادثات تنحفظ في متصفح الزائر (localStorage)، بدون تسجيل دخول.

## كيف يشتغل
- `index.html`, `styles.css`, `app.js` — الموقع (HTML/CSS/JS بدون أي بناء).
- `famous.js` — 39 شخصية أنمي وكرتون مشهورة كتقمّص من المعجبين: أنمي (ناروتو، لوفي، غوكو، كونان، غوجو، ليفاي، إيرين، ساسكي، إيتاتشي، كاكاشي، آش، ديكو، إدوارد، آنيا، شين تشان…)، كرتون زمان (عدنان، سالي، هايدي، كابتن ماجد، دايسكي)، وكرتون (سبونج بوب، باتريك، توم، جيري، سكوبي دو، دورايمون، بيكاتشو، تشوبر). الشخصيات البشرية بصور مرسومة بأسلوب المعجبين، والباقي بإيموجي.
- `characters.js` — شخصيات رفيق الأصلية.
- `portraits.js` — يرسم صور الأنمي للشخصيات (SVG)، وتقدر تصمم شكل شخصيتك منه.
- `config.js` — رابط دالة الدردشة.
- الردود من `supabase/functions/character-chat` (Gemini)، والمفتاح `GEMINI_API_KEY` في أسرار الدالة فقط.

## التشغيل محليًا
```sh
cd rafiq_web && python3 -m http.server 8080   # ثم افتح http://localhost:8080
```

## النشر
```sh
supabase functions deploy character-chat --no-verify-jwt
supabase functions deploy character-scene --no-verify-jwt
# الدوال تقبل افتراضيًا طلبات موقع https://ibraahimx2040x-lab.github.io فقط.
# لإضافة مواقع ثانية (مثل التجربة المحلية):
supabase secrets set ALLOWED_ORIGIN=https://ibraahimx2040x-lab.github.io,http://localhost:8080
```
وينشر GitHub Pages الموقع على `https://ibraahimx2040x-lab.github.io/cashier-updates/rafiq/` عند الدمج في `main`.

## صور الشخصيات

أي صورة تحطها في مجلد `rafiq_web/images/` باسم الشخصية (مثل `naruto.webp` أو `luffy.jpg`) تطلع بدل الرسمة لكل الزوار. خطوة النشر تبني قائمة الصور (`images/manifest.js`) تلقائيًا.
الصيغ المقبولة: jpg و png و webp. الأفضل صورة طولية (٤:٥) حجمها أقل من ٢٠٠ كيلوبايت.

لتوليد الصور بالذكاء الاصطناعي (يحتاج تفعيل الدفع على مفتاح Gemini):
```sh
node rafiq_web/tools/generate-images.mjs          # كل الشخصيات اللي ما لها صورة
node rafiq_web/tools/generate-images.mjs naruto   # شخصية معيّنة (يستبدل صورتها)
```
